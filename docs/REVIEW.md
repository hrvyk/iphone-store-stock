## 待實測關卡

四規格料號已與 Apple 香港官方購買頁逐一核對。舊 fulfillment-messages 端點實測回應 HTTP 541，已切換至現行 retail/pickup-message 端點，四規格全部回應 HTTP 200，六間門市共 24 格資料均完整。2026 年 10 月 25 日的這次回應全數為 unavailable，僅代表當時官網不提供取貨，並非永久庫存結論。

官方回應中 apm 名稱為 apm Hong Kong，已補對應並新增真實回應測試。21 項 Node 測試通過，包括 D1 遷移 SQL 的實際 SQLite 執行、來源解析、部分失敗、併發鎖、冷卻及錯誤退避。合成 available 測試輸入不會用於正式介面。

正式站點已發布，/api/status 回傳 24 格，/api/check 實際執行成功並保存完整結果。香港時間 2026-10-25 17:45:53 的檢測，24 格均為 unavailable。此次結果並不代表之後仍缺貨。

正式環境驗證發現 Workers 不支援 redirect:error，已改為 manual，禁止跨網域重導，並加上回歸測試。21 項測試、TypeScript 檢查與正式建置全部通過。

透過僅限本機的唯讀預覽驗證了實際發布介面、容量篩選與資料庫檢測紀錄。私人網站在一般瀏覽器要求 ChatGPT 登入；未代替使用者輸入帳密。預覽只在本機代理服務端授權讀取，並不改變正式站點的私人權限。

背景 writer 已使用平台服務授權執行並讀回 lastBackgroundAt；每小時原生雲端自動化已建立並啟用。建立排程不等於已完成第一個排程執行；首次自動執行結果以平台紀錄為準。關頁每 5 分鐘目前尚未常駐部署，已提供 Node 執行器原始碼。
