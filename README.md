# iPhone線下門店現貨查詢

以繁體中文提供香港 Apple 直營店 iPhone 取貨狀態查詢的 Web 工具，支援手機及電腦瀏覽。

> 本工具查詢 Apple 官網「可預約門市取貨」狀態，並非完整店內現貨，也不保證到店仍有貨。與 Apple 無隸屬關係。

## 主要功能

- 自動從 Apple 香港官網探索機型、容量、顏色及料號；亦可按「同步官網機型」手動更新。
- 查詢香港六家直營店：ifc mall、銅鑼灣、廣東道、又一城、apm Hong Kong 及沙田。
- 按機型、容量、顏色、門店及可取貨狀態篩選；列出可取貨門店、規格、時間及官網連結。
- 「刷新畫面」讀取已存資料；「重新檢測庫存」才會查詢官方來源。
- 顯示最後嘗試、最後完整成功、背景執行時間及最近檢測紀錄。
- 區分可取貨、不可取貨、未確認、來源錯誤及過期資料；失敗時保留先前紀錄。
- 手機版提供文字導覽、較大觸控按鈕、可換行篩選及可橫向捲動的庫存表，門店欄保持固定。

## 技術架構

React 19、TypeScript、Vinext／Vite、Cloudflare Workers、D1 SQLite 及 Drizzle ORM。`app/` 提供介面與 API；`lib/` 實作目錄探索、來源解析、冷卻與監測；`db/`、`drizzle/` 管理資料；`tests/` 包含測試資料，不代表即時庫存。

## 本機執行

需 Node.js 22.13 以上及專案鎖定版本的套件管理器。

```sh
npm run install:ci
npm run dev
```

本專案源自 ChatGPT Sites，保留 Sites 執行環境整合。正式環境需要 D1 `DB` 綁定、資料庫遷移及適用的驗證設定；GitHub 原始碼本身不會建立資料庫、私人網站存取權或背景排程。公開版本不含原站識別碼與存取憑證。移植至其他 Workers 環境時，需自行配置部署及驗證整合。

資料庫遷移存於 `drizzle/`。請在自己的 Wrangler 設定中將 D1 綁定命名為 `DB`，並把 `migrations_dir` 指向 `drizzle`，再透過 Wrangler 分別套用本機及正式環境遷移。

## 背景監測與限制

頁面自動檢測每 5 分鐘嘗試一次，關頁或休眠即停止。背景執行需另行設定排程或常駐執行器。現有服務配置每小時執行，並不隨公開原始碼移轉。

`node scripts/monitor.mjs` 可作獨立執行器，需透過環境變數提供 `SITE_URL` 與 `SITES_SERVICE_TOKEN`；不得將憑證提交至版本庫。此執行器適用已配置服務驗證的 Sites 網站。

官方來源可能限流、拒絕請求或改版。遇到限制會退避；資料超過 10 分鐘標示過期。同步失敗時保留舊目錄，不能保證未來機型一定可被解析。桌面／聲音提醒依瀏覽器支援及頁面開啟狀態而定，手機背景推播並未實作。
